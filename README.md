# AquaSky 

AquaSky is an intelligent multimodal navigation Android application designed to provide smarter and more flexible navigation across sea, air, and land transportation modes. It integrates interactive map visualization, route planning, weather awareness, and alternative route selection to help users make informed travel decisions. The application aims to combine different navigation facilities into a single platform, making transportation planning more accessible and convenient.

## Key Features

- **Multimodal Navigation:** Supports sea, air, and land navigation modes.
- **Smart Route Planning:** Allows users to enter origin and destination to find routes.
- **Fastest Route Selection:** Displays the fastest available route.
- **Alternative Routes:** Provides alternative route options for flexible navigation.
- **Interactive Map:** Uses OpenStreetMap with zoom and route visualization features.
- **Weather Information:** Displays current temperature, humidity, and wind speed.
- **Location Search:** Uses geocoding to search for locations.
- **Airplane Mode Integration:** Includes airplane mode-related functionality for air navigation.
